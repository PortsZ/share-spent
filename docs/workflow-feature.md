# Workflow: Implementing a Feature

This a workflow to implement a whole feature in the app, including frontend and backend logic.

## Workflow

- You will be given a description of a feature to implement
- Ask clarifying questions if something is unclear!
- Write a plan for yourself with tasks as todo items
- Implement feature step by step following the plan
- When you are finished, provide a short summary of what you did

## IMPORTANT HINTS

- Make sure you always understand coding rules from `docs/coding-rules.md`
- If you need to implement frontend components, use workflow from `docs/workflow-frontend-component.md`
- If you need to implement API endpoints, use workflow from `docs/workflow-api-endpoint.md`
- For UI components use Shadcn where it fits, so that our application does not copy code, (if its used elsewhere it should be a shared component.). Fetch latest Shadcn documentation via Context7 MCP.
- For UI animation, if you need them, use Motion. Fetch latest Motion documentation via Context7 MCP.
